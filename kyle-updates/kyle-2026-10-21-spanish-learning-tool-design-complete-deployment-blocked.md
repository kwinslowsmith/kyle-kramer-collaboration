## What I built

A mobile-first Spanish learning platform with five pages, all working locally with mock data:

1. **Homepage/Articles** — Newspaper-style feed of 3 sample Spanish articles (Colombian music, Pan de Muerto, García Márquez). Filter UI for region and content type. Clean typography with Garamond serif.

2. **Article Reading View** — Full article display with difficulty badge, comprehension questions (textarea), and writing prompts. Two-column layout on desktop.

3. **Glossary** — Three review modes: List (searchable with article source), Flashcard (gradient cards with word/definition reveal), Contextual (words in sentence context). 5 mock vocabulary entries.

4. **Notebook** — Personal journal for reflection entries. Tagged entries (e.g., "music", "colombia"), dated. Warm card-based layout.

5. **Writing Tracker** — History of writing submissions with prompts, user responses, and edit capability.

Navigation bar sticks to top, links all five sections.

## Design system

Two distinct visual systems (you were right that generic layouts are boring):

**Newspaper section** (Articles)
- Colors: Deep teal (#0d5f5f), black (#1c1917), cream (#faf8f3), grays
- Typography: Garamond serif, generous whitespace
- Aesthetic: Substack/editorial — high-quality, minimal
- Emphasis on readability and typography hierarchy

**Library section** (Glossary, Notebook, Writing)
- Colors: Jewel tones (burgundy #8b3a3a, gold #d4a574, navy #2c3e50, teal accents, cream)
- Typography: Garamond serif headers, warm atmosphere
- Aesthetic: Personal collection/archive — curated, bookish feeling
- Card-based layout with warm gradients

Why two systems: The reading experience should be clean and editorial (like a newspaper). The learning/study experience should feel like a collection you own and care about.

## Technical decisions

**Stack**: Next.js 16.2.6 + TypeScript + Tailwind CSS + Vercel + Supabase

**Styling approach**: Started with CSS variables in globals.css, switched to direct hex colors (#0d5f5f instead of var(--news-teal)) when Vercel didn't process CSS variables through inline React styles. This constraint became clearer code.

**Data**: Mock data in React components (Phase I). Prisma schema designed for 12-table PostgreSQL database (Articles, WritingPrompts, ComprehensionQuestions, UserGlossary, WritingSubmissions, Highlights, NotebookEntries, etc.) ready for Phase II.

**Deployment**: Separate repo from Viridian. GitHub: https://github.com/kwinslowsmith/spanish-learning-tool. Auto-deploy on push via Vercel.
